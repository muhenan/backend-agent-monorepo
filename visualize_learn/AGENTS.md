# Visualization Guidelines

Use these guidelines whenever adding or editing learning diagrams in this directory.

- Keep each architecture diagram concise and Mermaid-like. Show only the key components and main data flows.
- Use clear node names, labeled arrows, and short text. Avoid extra panels, decoration, and long explanations.
- Build each visualization as a standalone HTML file with inline SVG and CSS. Do not add external libraries or network dependencies.
- Make the diagram readable at a glance. Keep it within one screen on desktop and allow horizontal scrolling on narrow screens.
- Write labels in Chinese and use real component names, routes, and relationships from the project being explained.
- Add an accessible SVG title and description.
