① 文档入库

上传 PDF、DOCX、PPTX、XLSX、HTML、Markdown、TXT 或 CSV。Docling 将文档转换为 Markdown，再切块、向量化并写入 Qdrant。

等待上传。入库后会展示文档和 chunk 数。

数据流

文件 → Docling Markdown → paragraph-aware chunks → OpenAI embeddings → Qdrant
问题 → embedding → Qdrant top-k → 可见证据 → OpenAI Agent → 带引用答案

② 先检索，再让 Agent 回答

“只看召回”不调用生成模型；“检索 + 回答”会在同一组召回片段上运行 Agent。对比两者，能分辨是检索问题还是生成问题。
